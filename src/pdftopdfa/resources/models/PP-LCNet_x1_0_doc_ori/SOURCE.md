# PP-LCNet_x1_0_doc_ori

The bundled document-orientation model is derived from the official
`PaddlePaddle/PP-LCNet_x1_0_doc_ori` inference model at revision
`d3b95a6dff5fe8a94f2748e12b61cb26818a0df8`:

https://huggingface.co/PaddlePaddle/PP-LCNet_x1_0_doc_ori

The Paddle static model was converted to ONNX opset 7 with PaddleX 3.7.2,
Paddle2ONNX 2.0.2rc3, and PaddlePaddle 3.0.0.dev20250426. The model and its
upstream implementation are licensed under Apache License 2.0. The full
license text is included in `LICENSE`.
